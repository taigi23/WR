# WR — Weekly Report

選んだジャンルの業界ニュースを毎週集め、アイデアを記録するWebアプリ（GitHub Pagesで動作する単体版）。

- 本体：`index.html`（1ファイル）
- 現在のバージョン：アプリの「設定」画面の一番下に表示
- 変更履歴：[CHANGELOG.md](CHANGELOG.md)

## バージョンの付け方

`メジャー.マイナー.パッチ`（例：1.1.0）

- メジャー：保存データの形が変わるなど、互換性がなくなる変更
- マイナー：機能の追加・改善
- パッチ：不具合の修正のみ

リリースするときは、`index.html` の `APP_VERSION` と `CHANGELOG.md` を更新し、`v1.1.0` の形でタグを付けます。
